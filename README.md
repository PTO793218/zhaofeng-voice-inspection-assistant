# 兆丰语音操作助手及智能检测录入

面向生产现场的语音与文字操作原型，将任务查询、进度查看、生产报工和检测值录入放在同一个工作区。当前上传的是本地 8.21 版 React / TypeScript 原型。

## 主要流程

- 查询生产任务，选择候选后复用当前任务上下文。
- 查看任务进度，填写报工草稿，检查数量后人工确认。
- 进入智能检测录入，选择检测记录、项目和测量列，识别数值并人工确认。
- 语音和文字共用业务流程；支持语音反馈、失败提示及会话草稿恢复。

原型使用内置任务与检测样例。确认后的报工和检测结果只保存在浏览器演示会话中，没有连接或写入正式 MES 数据库。语音使用浏览器 Web Speech API，实际可用性取决于浏览器、麦克风权限和语音服务；文字操作可独立使用。

## 本地运行

使用兼容 Vite 8 的 Node.js（建议 Node.js 22.12 及以上）：

```powershell
npm ci
npm run dev -- --port 5821 --strictPort
```

打开 <http://127.0.0.1:5821/>。Windows 也可以双击仓库中的“启动网商语音助手原型.cmd”；局域网启动脚本使用相同端口。麦克风在局域网 HTTP 地址上的权限限制需在实际设备核对。

## 验证与构建

```powershell
npm test
npm run build
npm run test:sites
```

`build` 先运行 TypeScript 检查，再生成 `dist/client`，并准备 `dist/server` 和托管配置。仓库中的 `.openai/hosting.json` 未绑定现有托管项目；上传 GitHub 不代表部署网站。
