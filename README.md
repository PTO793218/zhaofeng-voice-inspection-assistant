# 兆丰语音操作助手及智能检测录入

面向生产现场的语音与文字操作原型，将任务查询、进度查看、生产报工和检测值录入放在同一个工作区。当前上传的是本地 8.21 版 React / TypeScript 原型。

## 项目展示

以下截图来自本仓库原型的实际运行页面。此次使用文字输入走语音与文字共用的业务流程，未进行麦克风识别验收；界面保留“演示环境 · 不写入 MES”标识。

### 1. 从任务线索找到具体工序

输入“打开 GP26030719”后，助手提取母任务号，返回对应的 6 个工序候选，并追问需要查看的工序。用户可以直接选候选，也可以继续补充工序名称；同一母任务下的不同工序不会被当成一个任务直接执行。

![自然语言解析任务线索，展示工序候选并提示补充信息](docs/screenshots/task-query.png)

### 2. 数量先校验，报工再人工确认

选定回火工序后，输入“完工18，报废0”即可形成报工草稿，保留当前任务上下文，并计算确认后的预计累计完成数 1,513。校验通过仍不自动保存，用户需检查并点击最终确认，保留复核数量和任务的机会。

![报工草稿显示完工数、报废数、预计累计完成数及人工确认入口](docs/screenshots/report-review.png)

### 3. 将检测指令定位到项目、列和数值

进入检测任务后，输入“检测录入，外径 D1，第 2 列，87.39”，助手准备对应单元格的待确认值，同时展示技术要求、上下限和只读历史值。实际点击确认后，87.39 只保存到本次页面会话，原第 1 列历史值 87.38 保持不变。

![智能检测录入展示检验项目矩阵及目标单元格的待确认数值](docs/screenshots/inspection-confirmation.png)

## 主要流程

- 查询生产任务，选择候选后复用当前任务上下文。
- 查看任务进度，填写报工草稿，检查数量后人工确认。
- 进入智能检测录入，选择检测记录、项目和测量列，识别数值并人工确认。
- 语音和文字共用业务流程；支持语音反馈、失败提示及会话草稿恢复。

原型使用内置任务与检测样例。确认后的报工和检测结果只保存在浏览器演示会话中，没有连接或写入正式 MES 数据库。语音使用浏览器 Web Speech API，实际可用性取决于浏览器、麦克风权限和语音服务；文字操作可独立使用。

## 本地运行

使用兼容 Vite 8 的 Node.js（建议 Node.js 22.12 及以上）：

```powershell
npm ci
npm run dev -- --port 5821 --strictPort
```

打开 <http://127.0.0.1:5821/>。Windows 也可以双击仓库中的“启动网商语音助手原型.cmd”；局域网启动脚本使用相同端口。麦克风在局域网 HTTP 地址上的权限限制需在实际设备核对。
